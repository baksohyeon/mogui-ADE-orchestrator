The workspace session card gains an optional file for installation-specific sections. `workspace-card/CLAUDE.md` and `AGENTS.md` (still byte-identical) now say: if `{{OPS_REPO}}/workspace-card/LOCAL.md` exists, read it after the card; its additions never override any rule on the card; absent, nothing changes. The pointer is plain prose, not an include, so every agent host reads it the same way. `workspace-card/LOCAL.md` is added to `INSTANCE_OWNED_EXACT` in `scripts/template_common.py`, so `template-apply` skips it as instance-owned and `template-check` does not report it as unknown; the template ships no copy and the manifest does not claim it. `onboarding/upgrade.md`, the `template-apply` header, and `workspace-card/README.md` (new "Local extension" section) name the path. `onboarding/upgrade.md` gains step 8, which redeploys the card pair to the workspace root with the owner's confirmation after a write pass rewrote it, so the pointer reaches the card the master reads. An existing install needs no action until it wants the file: move its own card sections into that file, then upgrade and redeploy the card pair.
