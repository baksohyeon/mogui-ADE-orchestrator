# Deprecated: worker-reap cleanup wrapper

`worker-reap` remains available for compatibility. Existing installations receive this guidance on their next template upgrade. Merged squash-merge pull requests now count as merged-PR evidence only when the PR base is the measured default branch of this repository, the PR head repository is this repository, and the PR `headRefOid` equals the measured branch tip; eligible worktree cleanup uses Orca's measured `terminal close` and `worktree rm` verbs when the installed binary exposes the required selector options, while other hosts keep the terminal-handle and Git fallback with the current refusal checks and reap ledger retained. An unavailable PR-state measurement is recorded as `pr_state_unmeasured` and does not veto an already ancestry-merged worktree, preserving the prior reclaim behavior. Legacy cleanup continues to refuse closure when an agent process is present or its cwd scan is unmeasured, because removing that worktree could lose active work; selector-backed cleanup also refuses when the worktree path is unmeasured because the agent-process cwd scan cannot be performed safely.
