The workspace session card gains an opt-in seat for installation-specific sections. `workspace-card/CLAUDE.md` and `AGENTS.md` (still byte-identical) now say: if `{{OPS_REPO}}/workspace-card/LOCAL.md` exists, read it after the card; its additions never override the execution rule; absent, nothing changes. The pointer is plain prose, not an include, so every agent host reads it the same way. `workspace-card/LOCAL.md` is added to `INSTANCE_OWNED_EXACT` in `scripts/template_common.py`, so `template-apply` skips it as instance-owned and `template-check` does not report it as unknown; the template ships no copy and the manifest does not claim it. `onboarding/upgrade.md`, the `template-apply` header, and `workspace-card/README.md` (new "Local extension" section) name the path. An existing install needs no action until it wants the seat: move its own card sections into that file after upgrading the card pair.
