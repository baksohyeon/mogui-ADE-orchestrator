`master-ops/scripts/dispatch` reads two optional instance runtime config keys for codex workers. `codex_reasoning_effort` (`minimal`, `low`, `medium`, `high`, `xhigh`, or `max`) replaces the hard-coded `xhigh` in both the launch line and the start-screen footer check, and `codex_bypass_approvals_and_sandbox: true` appends `--dangerously-bypass-approvals-and-sandbox` as an explicit operator opt-in and prints a warning on stdout. Only a codex dispatch reads the keys. Absent or null keys leave the launch line unchanged, and an invalid value stops a codex dispatch with exit 2. An installation that chose another effort or the bypass can now take template upgrades whole without losing that choice.
