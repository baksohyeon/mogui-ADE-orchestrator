`scripts/onboarding-preflight.sh` adds an essential `agent-route` check for a `claude` or `claude-code` agent CLI. It fails when `ANTHROPIC_BASE_URL`, `ANTHROPIC_AUTH_TOKEN`, or `ANTHROPIC_API_KEY` is set in the `env` block of `settings.json` in the Claude config directory (`$CLAUDE_CONFIG_DIR`, default `~/.claude`) or in the shell, and names each source it found (`settings.env.<VAR>`, `shell.<VAR>`). A `settings.json` it cannot read fails as an unmeasured route. Measured case: a vendor setup command (`vercel ai-gateway setup`) rewrote the agent config to a proxy that did not serve the configured model, and every request failed with 429 with nothing pointing at the rewrite. `PREFLIGHT_ALLOW_AGENT_PROXY=1` turns an intentional proxy or direct-key override into a PASS that names the route; `PREFLIGHT_WAIVE=agent-route` also works as for any check. For any other agent CLI, or none selected, only `agent-route` itself reports not measured, so the essential label stays visible; with `ORCA_AGENT_CLI` unset, the separate `agent-cli` failure stands. `master-ops/onboarding/01-preflight.md` lists it under Verify.
