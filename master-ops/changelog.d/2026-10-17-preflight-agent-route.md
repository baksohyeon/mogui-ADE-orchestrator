`scripts/onboarding-preflight.sh` adds an essential `agent-route` check for a `claude` agent CLI. It fails when `ANTHROPIC_BASE_URL`, `ANTHROPIC_AUTH_TOKEN`, or `ANTHROPIC_API_KEY` is set in the `env` block of `~/.claude/settings.json`, or `ANTHROPIC_BASE_URL` or `ANTHROPIC_AUTH_TOKEN` is set in the shell, and names each source it found (`settings.env.<VAR>`, `shell.<VAR>`). Measured case: a vendor setup command (`vercel ai-gateway setup`) rewrote the agent config to a proxy that did not serve the configured model, and every request failed with 429 with nothing pointing at the rewrite. `PREFLIGHT_ALLOW_AGENT_PROXY=1` turns an intentional proxy into a PASS that names the route; `PREFLIGHT_WAIVE=agent-route` also works as for any check. Other agent CLIs are not measured by this check. `master-ops/onboarding/01-preflight.md` lists it under Verify.
