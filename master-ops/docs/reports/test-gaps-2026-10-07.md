# Test gaps, round two: twelve behaviours that broke and what pins each one now

Scope: the twelve behaviours the contract lists. Round one wrote the placement rules into
`CONTRIBUTING.md` ("Adding a test"); this round maps each gap to a test type and a place under those
rules. Round three implements the rows.

## Method

Every `covered` and `fix-flaky` row below was run once, foreground, on 2026-10-07; the pasted line is
that run's own output, not a transcription from an earlier report. Four `pytest`/`shell-inline` gap rows
with no case yet (6, 7, 9, 10) got the same evidentiary bar anyway: each cites a check made today, direct
against the source under test or against the tracked tree, as evidence that the gap is real now, not a
hypothetical.

Two path bases appear in the `what pins it now` and `placement` columns. A path with no prefix for a
template subject (`scripts/test-dispatch-runtime.sh`, `scripts/worker-pane-sweep`, `changelog.d/...`, and
the rest of rows 1, 3, 4, 5, 8, 9, 10, 11, 12) is root-relative to this template's own tree, the convention
this report's directory already follows. A path for an orchestrator-runtime subject is root-relative to
the repository that carries this template, one level above it, since those files are the orchestrator's
own code and never ship as part of the copied template tree: `scripts/dispatch-gate` in row 6,
`src/master_runtime/core/dispatch_gate.py` in row 7, `tests/test_dispatch_gate.py` in rows 6 and 7,
`CONTRIBUTING.md` and `.github/workflows/gates.yml` in row 8, and `tests/test_changelog_release.py` in
row 9.
