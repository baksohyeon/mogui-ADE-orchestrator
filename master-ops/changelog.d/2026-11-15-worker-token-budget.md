Added declared and measured worker token budgets, provider usage readers, and the pre-dispatch Codex quota guard to the dispatch wrapper. Tier defaults use recent complete worker records with a minimum sample count, host-recorded worktree evidence, an atomic cache, and a two-second computation bound with cache fallback; Codex quota reads are scoped to the dispatch account, cap file and tail reads, and fail open when the account or snapshot is unknown. Settlement remains compatible with omitted runtime metadata, records pre-registration completions, and upgrades an earlier unmeasured result when a later measured result arrives.
