`master-ops/scripts/dispatch-smoke` now prints the artifact it judged to stderr before its `cleanup` trap removes the scratch state directory and worktree. A new `print_artifact LABEL PATH [MAX_LINES]` function writes the label, the path, and one of `absent`, `empty`, the first `MAX_LINES` lines of a file (5 by default), or an `ls -la` listing for a directory. The five branches that previously named a step and exited with nothing left to inspect call it before `FINAL_RC` is set: `no-scratch-ledger-row` (the ledger file and the `$STATE` directory), `leak` and `concurrent-writer` (the ledger path, alongside the added rows that already printed), `contract-read step=missing` (`SMOKE.txt` and the worktree root), and `contract-read step=mismatch` (`SMOKE.txt`). Stdout is unchanged: every `smoke FAIL ...` line and the pass line keep their exact text. `master-ops/docs/runbooks/dispatch-smoke.md`'s look-next table points each affected row at the label its print uses.
